# SysProcOverview

**SysProcOverview** (System and Process Overview) is a lightweight system utility designed to inspect individual running processes and provide a quick snapshot of overall system resource utilization.

## Features

- **Detailed Process Inspection:** Retrieve actionable information for running processes, including binary names, file paths, CPU consumption, and memory usage.
- **System Resource Overview:** Get an instant summary of overall system status, featuring total CPU usage, memory allocation, and system uptime since boot.
- **Clean & Concise Output:** Delivers clear metric overviews straight to your terminal without clutter.
